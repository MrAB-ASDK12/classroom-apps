Clip Shelf

Good teaching ideas turn up in Instagram videos, then disappear into a long Saved list. Clip Shelf is a browser extension that saves Instagram posts and reels into boards, the way Pinterest saves pictures. It saves the link, the account name, the caption and a small preview picture. It doesn't download videos: clicking a card plays the clip on Instagram.

What you get

Your boards, Pinterest-style

  • On Instagram, point at a post or reel and a red Save button appears. You can also right-click a post.
  • Pick or create a board, then add tags or a note.
  • Your library shows clips as cards. Search, filter by tag, and drag cards onto a different board.
  • + Add by link takes links you texted yourself from your phone.

Installing it

Clip Shelf isn't in the Chrome Web Store, so you add it by hand. It takes about five minutes, one time.

  1. Download and unzip. Click the download button above, then unzip the file somewhere you'll keep it, such as Documents. Don't delete the folder later: Chrome runs the extension from it.
  2. Open the Extensions page. In Chrome, type chrome://extensions in the address bar. In Edge, type edge://extensions.
  3. Turn on Developer mode. It's a switch on the Extensions page (top right in Chrome).
  4. Load it. Click Load unpacked and choose the chrome-extension folder inside the folder you unzipped.
  5. Pin it. Click the puzzle-piece icon in the toolbar and pin Clip Shelf so its icon is always showing.
  6. Try it. Open instagram.com, point at a post, and click the red Save button. Click the Clip Shelf icon, then Open my library.
Back up now and then. Your clips live only in Chrome on this computer. Use Back up library (.json) in the library, and restore it later or on another computer with Restore from a backup. Export list (.csv) opens in Excel, Numbers or Google Sheets. Never click Remove on the Extensions page: that deletes your saved clips.

Optional: see your boards on an iPad

Extensions don't run on an iPad. The google-sheet-code folder in the zip connects Clip Shelf to a Google Sheet you own. The Sheet holds your library, and a web page opens it on both the iPad and the computer. Setup is a one-time job: make a Sheet, paste in the code, deploy it as a web app, then paste your private connection link into Clip Shelf's settings. Add that same link to your iPad's home screen to open your boards there.

Things to know.
  • School-managed computers often block extensions you install yourself. If Load unpacked is missing or greyed out, use a personal computer.
  • Some school Google accounts don't allow the web-app step for the iPad add-on. A personal Google account works.
  • Instagram changes its page layout often. If the red Save button stops appearing, right-click saving and + Add by link still work.
  • Clip Shelf isn't made by or affiliated with Instagram or Meta.
